# Experiment 4 — Adaptive Retrieval Router

- `RAG_Exp4_Colab.ipynb` — self-contained Colab notebook. Upload `../data/docs.jsonl`
  and `../data/qa_final_180.jsonl` when prompted, run all cells top to bottom.
- `router_demo.html` — a live, in-browser interactive demo of the router logic
  (open directly in any browser, no server needed; uses a lightweight TF-IDF stand-in
  for the paper's dense embeddings so it works fully offline).
- `EXPERIMENT4_ADDENDUM.md` — methodology writeup for this experiment.
- After running the notebook, four output files download from Colab:
  `experiment4_results.json`, `experiment4_confusion_matrix.csv`,
  `experiment4_comparison_table.csv`, `experiment4_router_errors.csv` — save them in
  this folder once you have them.
